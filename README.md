# Proyecto-Intermodular-SMR-V-ctor-San-Rom-n1
Proyecto intermodular de Víctor San Román

En este proyecto, presentaremos una empresa cuyo objetivo sera el funcionamiento ideal de esta misma. Tendremos que pasar por campos como redes o sistemas operativos monopuesto para garantizar el éxito de la empresa.

El orden que este seguira sera el siguiente:
1-  IPE
2-  Redes
3-  Montaje y mantenimiento de equipos
4-  Sistemas operativos monopuesto
5-  Ofimática
6-  Fundamentos de computación en la nube
